# Timoi-ECars

A Tesla landing page clone built with HTML, CSS, and JavaScript, recreating the look and feel of Tesla's marketing homepage.

## Features

- Hero section with vehicle imagery and model highlights
- Navigation bar styled after Tesla's site
- Interactive elements powered by JavaScript (e.g. menus, buttons, or model switching)
- Tesla-inspired minimalist design and typography
- Responsive layout across screen sizes

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sunkulitimoi-creator/Timoi-ECars.git
   ```
2. Open `index.html` in your browser — no build step or dependencies required.
